🎯 Tujuan Pembelajaran
  • 1Peserta didik mampu menjelaskan pengertian dan konsep dasar struktur data tree (pohon) beserta istilah-istilah penyusunnya (root, node, child, parent, leaf).
  • 2Peserta didik mampu mengidentifikasi karakteristik dan jenis-jenis struktur tree, termasuk binary tree, dalam konteks penyelesaian masalah komputasional.
  • 3Peserta didik mampu menyusun representasi data ke dalam bentuk struktur tree yang sesuai untuk menyelesaikan masalah sederhana secara logis dan sistematis.
  • 4Peserta didik mampu menjelaskan proses penelusuran (traversal) pada struktur tree serta menerapkannya pada simulasi sederhana.
Materi Pembelajaran
📖 Struktur Data Tree
🌳
Apa itu Tree?
Tree adalah struktur data hierarkis yang menghubungkan node-node dalam bentuk cabang, mirip pohon terbalik, tanpa siklus.
🔵
Root & Node
Root adalah node teratas/akar tree. Node lain terhubung sebagai anak (child) dari node induk (parent).
🍃
Leaf Node
Leaf adalah node paling bawah yang tidak memiliki anak lagi, menandai akhir sebuah cabang.
🔀
Binary Tree
Binary tree adalah tree khusus di mana setiap node maksimal memiliki dua anak: kiri dan kanan.
🧭
Traversal Tree
Traversal adalah proses menelusuri seluruh node tree, misalnya secara preorder, inorder, atau postorder.
🗂️
Penerapan Tree
Tree digunakan untuk struktur folder, silsilah keluarga, menu aplikasi, hingga sistem pencarian data.
